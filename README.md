# DriveGo

DriveGo is a driving route discovery platform for car enthusiasts and road trip lovers. Browse scenic routes, explore interactive maps, share recommendations, and customize the experience with nine themes.

Built with HTML, CSS, JavaScript, and Bootstrap 5, DriveGo features a responsive design, smooth animations, and route management tools.

## Getting Started

Clone the repository and run a local server:

```bash
python -m http.server 8000
```

Open `http://localhost:8000` in your browser.

## Tech Stack

- HTML5, CSS3, JavaScript
- Bootstrap 5
- WOW.js and custom CSS animations
